# 1. Project Overview

STAY Properties is a hypothetical South African property business created for this academic website project.

The purpose of the website is to provide potential buyers and tenants with clear information about the organisation, available properties, enquiry options and contact details.

The website is designed to provide users with an easy and professional way to browse property information and communicate with STAY Properties.

Part 1 of the project focuses on creating the basic website foundation using **HTML5**. The website structure has been created so that CSS can be added in Part 2 and JavaScript functionality can be added in Part 3.

The website is designed to be:

- Informative
- Professional
- Easy to navigate
- User-friendly
- Accessible
- Organised
- Ready for future development

# 3. Website Goals and Objectives

The main goals of the website are to:

1. Provide information about STAY Properties.
2. Display available residential properties.
3. Allow users to make property enquiries.
4. Provide clear contact information.
5. Provide information about the company's locations.
6. Create an easy-to-use navigation system.
7. Provide a professional online presence for the organisation.
8. Prepare the website for CSS and JavaScript development.

### Key Objectives

The website should:

- Contain at least five pages.
- Have working navigation between pages.
- Provide property information.
- Include images with alternative text.
- Include an enquiry form.
- Include a contact form.
- Include two business locations.
- Provide Google Maps links.
- Use semantic HTML5 elements.
- Have a clear and organised file structure.

# 4. Website Pages

The website contains five main pages.

| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Introduces STAY Properties and provides calls to action |
| About Us | `about.html` | Provides company information, mission, vision and team information |
| Properties | `services.html` | Displays available residential properties |
| Enquiry | `enquiry.html` | Allows users to make property enquiries |
| Contact | `contact.html` | Provides contact information, locations and contact form |

All five pages are connected using the main navigation menu.
